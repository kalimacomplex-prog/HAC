⚡ O que é o HAC?

O HAC (Hub Agent Controller) é uma plataforma para cadastrar, agendar e executar scripts Python remotamente em qualquer máquina. Você escreve o processo uma vez no painel web e o agente instalado na máquina executa automaticamente.

🌐
Painel Web
Crie processos, agende cron jobs e veja os resultados
🔁
API Central
Coordena jobs entre o painel e os agentes via REST
🤖
Worker (Agente)
Roda na máquina local e executa os scripts Python

⬇ Download do Worker

Baixe o executável do agente para a máquina onde os scripts vão rodar. Na primeira execução ele configura tudo automaticamente.

Linux: após baixar, abra um terminal na pasta do arquivo e execute:
chmod +x HAC-Worker-Linux.sh && ./HAC-Worker-Linux.sh

🛠 Instalação passo a passo

1
Crie um Agente no painel
Vá em Agentes → + Novo agente, dê um nome (ex: "Meu Notebook") e salve. Copie o ID gerado clicando em 📋 Copiar ID.
2
Execute o HAC-Worker.exe
Dê dois cliques no executável baixado. Na primeira execução ele vai perguntar suas credenciais e criar os arquivos de configuração automaticamente em:
C:\Users\<usuario>\AppData\Local\HACWorker\
3
Preencha as informações solicitadas
O worker vai pedir:
URL da API: https://hac-api-ojt8.onrender.com
Seu e-mail: seu@email.com
Sua senha: ••••••••
ID do agente: (cole o ID copiado no passo 1)
4
Worker conectado!
O agente aparecerá como ● Conectado na tela de Agentes. Um atalho "Iniciar HAC Worker.bat" é criado na Área de Trabalho para facilitar a inicialização.

📋 Como criar e executar processos

1. Crie um Processo — Vá em Processos → + Novo processo. Escreva ou importe um script .py. Associe ao agente desejado.

2. Execute — Clique em ⚡ Executar para rodar imediatamente, ou em ▶ Com parâmetros para passar valores via JSON.

3. Acompanhe — Clique no nome do processo para ver o histórico de execuções com output e erros. O Dashboard mostra o resumo geral.

4. Agende — Em Cron Jobs → + Cadastrar configure execução automática por intervalo, horário diário ou expressão cron.

⚙ Parâmetros nos scripts

Passe valores para seus scripts via variáveis de ambiente com o prefixo HAC_PARAM_:

import os

# Acesse os parâmetros passados ao disparar o job
url   = os.environ.get('HAC_PARAM_URL', '')
limit = os.environ.get('HAC_PARAM_LIMIT', '10')

print(f"Processando {url} com limite {limit}")

Ao disparar com parâmetros, informe o JSON: {"url": "https://exemplo.com", "limit": "50"}

📦 Instalando bibliotecas Python

Se um script falhar com ModuleNotFoundError, aparecerá automaticamente um botão 📦 Instalar biblioteca no log do erro. Basta clicar — o agente instala o pacote no ambiente Python isolado.

Para instalar manualmente, abra um terminal e use o pip do ambiente do worker:

"%LOCALAPPDATA%\HACWorker\env\Scripts\python.exe" -m pip install nome-da-biblioteca

🔄 Reinstalar ou reconfigurar o worker

Para remover e reinstalar do zero, delete a pasta abaixo e rode o .exe novamente:

C:\Users\<usuario>\AppData\Local\HACWorker\

O worker vai recriar tudo do zero na próxima execução.
